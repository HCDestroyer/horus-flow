## Nuevo

- **Alta manual de routers: ningún puerto HTTPS abierto.** Si el servidor de Horus tiene IP privada, ya no hace falta publicar el 443. En el router de borde basta con reenviar el UDP de WireGuard, que no responde a quien no tenga una clave registrada. Al generar el script de alta activa «Alta manual»: el router no se conecta a Horus, muestra su clave pública al terminar y tú la pegas en el panel desde tu red. La clave privada sigue sin salir del router, y el token conserva sus reglas (un solo uso, 24 h). Guía en `docs/install-debian.md` §5.1.
- **Panel limitado a tus IPs (`--panel-allow`).** Si publicas el puerto 443 con un dst-nat porque el servidor tiene IP privada, ahora puedes limitar el panel, la API y el tiempo real a las IPs o redes que elijas. El alta de routers nuevos y el túnel WireGuard siguen abiertos para todos, así que el exportador sigue activo y un router se da de alta desde cualquier sitio. Se activa al instalar o volviendo a ejecutar el instalador (`--panel-allow 190.0.2.10,192.168.88.0/24`), o con `HORUS_PANEL_ALLOW` en el stack de Portainer. Guía y reglas de NAT para MikroTik en `docs/install-debian.md` §5.1.
